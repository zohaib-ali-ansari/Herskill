# HerSkill

HerSkill is a women-only online marketplace that connects skilled women with female customers.

## Technology Stack

**Frontend**
- React.js
- Vite
- JavaScript
- Tailwind CSS

**Backend**
- Node.js
- Express.js
- MongoDB with Mongoose
- dotenv
- CORS
